# Succo di lampone: ottimizzare Java e PHP su Raspberry Pi Cluster

Slide e materiale del talk presentato da **Matteo Baccan** a **Codemotion Roma 2014**.

## Descrizione del talk

Sessione tecnica dedicata a chi usa già Linux come ambiente di sviluppo per applicazioni **Java e PHP** e vuole capire come portare il proprio lavoro su **Raspberry Pi**, ottimizzarne la configurazione e sfruttarne le potenzialità in un'architettura cluster.

## Argomenti trattati

- **Raspberry Pi** — versione standard e Compute Module
- **Sistemi operativi** — Raspbian, RiscOS e varianti (Base e Server)
- **Ottimizzazioni di sistema** — overclock hardware, rimozione servizi superflui
- **PHP su Raspberry Pi**
  - Stack LAMP, NGINX, Monkey, Lighttpd
  - Configurazione cluster con HAProxy
  - Benchmark comparativo tra server web
- **Java su Raspberry Pi**
  - Installazione su Raspbian
  - Benchmark prestazionali
- **Raspberry Pi emulato** — utilizzo tramite QEMU
